Point, grab, move, resize, wait.

The cursor is the first thing that tells people what they can do. Cursory puts every CSS cursor value inside the interface it was made for, so you can feel the difference, then copy the one line you need. Hover the headline to start.

Cursors only appear with a mouse or trackpad. On this device you can still read each value, try the demos, and copy the CSS.
